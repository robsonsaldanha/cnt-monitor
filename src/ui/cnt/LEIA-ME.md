# Base de front-end CNT (cópia)

Estes arquivos vêm do framework de front-end CNT (repositório `robsonsaldanha/cnt-front-end`):
fundação (`cnt.css`, `tokens.css`, `base.css`, `temas/`, `tema.js`), temas de estilo (`_estilos/`),
modelos de componente (`base-*/modelo-*/nucleo/`), sidebar, topbar, modal e editor de fluxos (`fluxo.css`, `fluxo.js`, de `base-fluxos/modelo-editor/nucleo/`).

Não edite aqui: mude na origem e copie de novo, mantendo as mesmas pastas
(as folhas de `_estilos/` importam `../base-*/`). O que é só do CNT Monitor fica no CSS de `../index.html`.
