Limpar o cache de memória

Esvazia a memória que o Windows guarda “de reserva” (lista de espera). Normalmente não ajuda — o Windows já libera esse cache sozinho quando precisa, e limpar faz os programas demorarem um pouco mais para abrir de novo. Use só se um jogo estiver dando travadinhas mesmo com memória sobrando.

Manutenção do Windows

ferramentas do próprio Windows
Otimizar unidades
Faz o TRIM nos SSDs e desfragmenta HDs (o mesmo que “Desfragmentar e otimizar unidades”). Seguro e pode ser feito com o PC em uso.
Limpar componentes antigos do Windows
Remove versões antigas de atualizações que o Windows já substituiu (DISM StartComponentCleanup). Não desinstala atualizações atuais. Pode levar de 5 a 20 minutos.

Regras por programa

Diga o que fazer automaticamente com um programa sempre que ele estiver aberto: prioridade, quais núcleos ele pode usar, não deixar abrir, avisar quando abrir ou quando passar de um limite de memória. Programas do Windows nunca são alterados.
