Limpar o cache de memória

Esvazia a memória que o Windows guarda “de reserva” (lista de espera). Normalmente não ajuda — o Windows já libera esse cache sozinho quando precisa, e limpar faz os programas demorarem um pouco mais para abrir de novo. Use só se um jogo estiver dando travadinhas mesmo com memória sobrando.
